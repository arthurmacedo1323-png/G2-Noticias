# G2 Notícias

Portal de notícias genérico desenvolvido em HTML, CSS e JavaScript como trabalho de front-end.

## Estrutura do projeto

- `index.html` — página inicial com destaques, notícias e rodapé
- `login.html` — página de login
- `cadastro.html` — página de cadastro
- `cms-admin.html` — painel administrativo do portal
- `css/style.css` — estilos do site
- `js/script.js` — interações do site e validações de formulários

## Como executar

1. Abra a pasta do projeto no seu computador.
2. Dê duplo clique em `index.html`.
3. O site será carregado no navegador.

Ou, se preferir, pode abrir via servidor local com VS Code Live Server ou qualquer servidor HTTP simples.

## Observações

Este projeto foi montado para funcionar como uma estrutura pronta para apresentação, com visual moderno, responsivo e navegável entre as páginas principais.
